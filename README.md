# Umbra Dotfiles
Full-featured Linux MangoWM rice aimed at providing parity with desktop environments (Work In Progress).

https://github.com/user-attachments/assets/d7d50b90-02a5-4a8a-a465-8f42ad6659b5

# Installation
> [!IMPORTANT]
> A working barebones installation of Arch Linux or a distribution of Arch Linux, such as EndeavourOS (recommended), is required.

To install, clone the GitHub Repository and run the `install.sh` script:
```sh
git clone https://github.com/nautrw/umbra-dots && cd umbra-dots && sh install.sh
```

# Features
- Custom and interactive install script that allows the user to control what commands are ran
- Bar with useful information and applets
- Bluetooth and clipboard manager support
- Ergonomic keybinds for many things
- Custom wallpaper changer per monitor with a keybind (Meta+W)
- Consistent Adwaita theming on all major GTK and QT apps

# Technologies used
- [MangoWM](https://mangowm.github.io/)
- [MangoBar](https://github.com/mangowm/mangobar)
- [Dunst](https://github.com/dunst-project/dunst)
- [Fuzzel](https://codeberg.org/dnkl/fuzzel)
