# Umbra
Linux rice based on the Adwaita theme/design language using MangoWM.

https://github.com/user-attachments/assets/16b98bc3-bd75-4c94-b3e5-ffb0bf5ad06f

###### Note to Hack Club: A normal demo wasn't possible because this is meant to be installed as the desktop environment and thus does not fit the general project categories

# Installation
**Requirements**: A clean install of an Arch Linux-based distribution (this was designed to be used on EndeavourOS)

1. Clone the github repository
```sh
git clone https://github.com/nautrw/umbra-dots
```

2. Run the install script and folloow the prompts
```sh
cd umbra-dots && sh install.sh
```

# Features
- Intelligent installation script that handles failed commands & shows the user what is being ran
  - Options for terminal file choooser (yazi)
- Consistent Adwaita theming across GTK and QT apps
- Ergonomic keybinds (random wallpaper setter, moving windows to different monitors, etc.)
- Many quality-of-life features (clipboard manager, emoji picker, bluetooth, etc.)
